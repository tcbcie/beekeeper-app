WP05 – Apply accessible colour and status tokens

Plan: docs/features/mobile-first-implementation-plan.html (WP05 and refinements). Findings: F04, D08, H06, R05, V10, V14, V15, V17, and the colour part of D07. Ratios below were worked out from the actual colour values (WCAG formula); targets are 4.5:1 for text and 3:1 for field edges and icons.

Changes

  1. Green text everywhere (F04, D08, V10). src/app/globals.css, next to the existing "darken coloured text in light mode" block, which already does this for green, amber, red and others:
    • Light: text-forest-600 (123 uses, 3.30:1 on white) and text-forest-700 (50 uses, 4.45:1 on elevated cream) both show as forest-800: 7.13:1 on white, 6.33:1 on elevated cream.
    • Dark: forest-600 or forest-700 text with no dark colour of its own shows as forest-400 (8.42:1, was 4.45:1). The selector is .dark .text-forest-600:not([class*="dark:text-"]), so the 79 uses that already set a dark colour keep it.
    • One side effect: links that changed shade on hover (hover:text-forest-700, 18 uses) no longer do in light mode. The existing green and amber overrides already behave this way, and most of these also underline on hover.
  2. "View Changes" link inside a sentence (V17), src/app/dashboard/page.tsx: always underlined. Colour alone was its only marker, at 2.26:1 against the text around it.
  3. Full Size badge (H06, V14), HiveListCard.tsx: it had dark-only colours, giving 1.74:1 in light. It gets light colours (emerald-800 on emerald-100, 6.78:1) and keeps its dark ones.
  4. Field edges (R05). The shared border is 1.26:1 on white, so fields are hard to find. A new --field-border colour is used only for text fields, drop-downs and text areas:
    • Light: warm grey #857d74, at least 3.59:1 on white, cream and elevated cream.
    • Dark: slate #71809a, at least 3.66:1 on dark surfaces.
    • Used by .fj-control, and by plain input/select/textarea elements that use border-border, when not focused. A focused field keeps its own focus colour.
    • Cards, panels and dividers keep the light shared border.
  5. Voice note button (V15), InspectionForm.tsx: purple-600 in both themes (5.38:1; dark used purple-500 at 4.12:1). "Transcribing…" changes from purple-400 (2.64:1) to purple-700 (6.98:1), so its words can be read.
  6. Mel button (D07 colour), ChatButton.tsx: forest-800, hover forest-900, like every other green button. It was forest-600 (3.30:1), which the earlier white-on-green fix missed because the white is on the icon. Its label and prominence are WP08.

Not changed

  • Status pills, badges and card styles in general: WP08, so this package is colour fixes only.
  • Queen marking and hive configuration colours: meaningful, and kept.
  • Already-corrected white-on-green and white-on-amber fills: left as they are.
