Frame-Direction Marker on Half-Box-Only Hives

Problem

The Hives list card draws the frame direction (warm or cold lines) only on the bottom full-size brood box. Since the phantom-box fix (e6cba3c), a hive with only half-size brood boxes has no full box to draw it on, so its frame direction is not shown at all. Before that fix, the marker sat on the phantom full box.

Impact (live DB): 3 active hives have only half boxes, and 2 of those have a frame direction set.

Before and after (half-box-only hive, cold frames)

Proposed: marker on the bottom half box

Rule

The marker goes on the bottom brood box. That is the last full box if there is one, otherwise the last half box. Hives with any full boxes look exactly as they do today.

Plan (one file: src/components/hive/HiveListCard.tsx)

Add halfBroodBoxes = brood_boxes_half ?? 0 next to fullBroodBoxes, and use it in the half-box loop (replacing || 0; behaviour is the same).
Move the existing warm/cold marker JSX into a single frameOrientationMarker constant (null when no direction is set), so it isn't duplicated.
Full-box loop: render frameOrientationMarker on the last full box. The output is unchanged.
Half-box loop: when fullBroodBoxes === 0, render it on the last half box. That box gets relative, and its label gets the same relative z-10 wrapper the full box uses, so the text stays above the lines.
Lint, type-check and run the QA audit.
Update docs/features/hive-card-zero-full-brood-fix-plan.md.
You check a half-box-only hive with a frame direction, and a normal hive, on the Hives page.
Out of scope: the 3D apiary view and the hive form. Only the list card draws this marker.

Review

  • HiveListCard.tsx: the marker JSX moved into one frameOrientationMarker constant (no duplication). It is drawn on the last full box, or on the last half box when there are no full boxes. Added halfBroodBoxes = brood_boxes_half ?? 0.
  • Hives with full boxes give identical output. The two placements are mutually exclusive, so the marker is drawn at most once.
  • ESLint is clean and there are no type errors in src/. QA found no Critical, High or Medium issues.
  • Doc updated: docs/features/hive-card-zero-full-brood-fix-plan.md.

Please test

  1. Hives page: a hive with only half boxes and a frame direction set should show the warm or cold lines on its bottom half box, with the label still readable.
  2. A normal hive with full boxes should show the lines on its bottom full box, as before.
