Breeder Queen Display Fix

Problem

The batch list shows "N/A" for breeder queen when queens are linked via the batch_breeder_queens junction table instead of the single mother_queen_id FK on rearing_batches.

Root Cause

The Supabase query only joins queens!mother_queen_id(queen_number). Batches that use the many-to-many junction table have mother_queen_id = null, so batch.queens is null and the display falls back to "N/A".

Fix (single file: batches/page.tsx)

  1. Add batch_breeder_queens(queens(queen_number)) to the select query
  2. Add batch_breeder_queens array type to the Batch interface
  3. Create a helper to extract breeder queen display: mother_queen_id first, then junction table, then "N/A"
  4. Use the helper in both mobile card and desktop table views
