Monthly tasks editor

Status: built, approved by the owner. Not yet tested in a browser or committed.

Today

The dashboard's "{Month} in Ireland" panel reads monthly_apiary_tasks. The app can only read that table, so the text can only be changed in the Supabase dashboard.

Proposal

  • Where: a new "Monthly tasks" section on the Settings page, next to dropdown management.
  • Who: admins only, enforced in the database with the same is_current_user_admin() check that dropdown values use. Everyone else keeps read-only access.
  • What: choose a month, then edit an item's text, add one, delete one, or move it up or down.
  • Limit: at most 5 items a month, enforced in the database as well as on the page.
  • Review date: the panel's "Reviewed October 2026" is fixed text and would go out of date after an edit. It will come from the last time that month's list was changed.
  • Timing: a change shows the next time a user loads the app, as the panel keeps the month's list until then.
