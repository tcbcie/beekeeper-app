Mating Nucs — “Nucs by Batch” summary

Request

The per-run details (Requested/Created) added no value and no longer reconciled with the batch-level “View Nucs” filter. Replace the Bulk Nuc Runs table with a per-batch summary: each batch’s total nuc count and a breakdown by status (Cell Introduced, Virgin Queen, etc.), keeping the batch filter.

Approach

The summary is computed inside fetchNucs via one extra, filter-independent query (active non-inventory nucs grouped by batch_id + status). Because fetchNucs already runs after every create/edit/retire/delete/bulk action, the summary stays in sync with zero extra wiring.

Review
