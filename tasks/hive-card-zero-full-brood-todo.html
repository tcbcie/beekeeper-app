Hive Card Shows a Full Brood Box That Isn't There

Problem

Hive xx (apiary Home) is configured with 0 full-size and 1 half-size brood boxes, but the Hive Setup drawing on the Hives list card shows "Brood Half 1" and "Brood Full 1".

Root cause

The stored configuration is {"brood_boxes_full": 0, "brood_boxes_half": 1, "brood_boxes": 1, ...}. brood_boxes is a legacy total that the hive form still always writes as 1.

HiveListCard.tsx:470 counts full boxes with brood_boxes_full || brood_boxes || 0. Because 0 is falsy, a deliberate "0 full boxes" falls through to the legacy 1. Line 474 (the frame-orientation marker on the last full box) has the same || chain.

The legacy fallback is only meant for old hives that have no brood_boxes_full at all. The 3D apiary view (Hive3D.tsx:50) and the inspection form (InspectionForm.tsx:1101) already get this right with ??. The hive card is the only reader that uses ||.

Plan (one file: src/components/hive/HiveListCard.tsx)

Work out the full-box count once, as brood_boxes_full ?? brood_boxes ?? 0, and use it for both the box loop (line 470) and the last-box check for the frame-orientation marker (line 474).
Lint, type-check and run the QA audit.
Add a feature doc in docs/features.
You check that hive xx shows only "Brood Half 1".
No data change is needed: the stored config is correct, and only the drawing misreads it. Changing what the form writes to the legacy brood_boxes field is out of scope. No reader depends on it once this is fixed.

Review

  • HiveListCard.tsx: one new constant, fullBroodBoxes = brood_boxes_full ?? brood_boxes ?? 0, used by the full-box loop and the frame-orientation marker. Two || chains removed.
  • Impact: 7 active hives had a phantom full box, and all are fixed by this render change. No data was changed.
  • ESLint is clean and there are no type errors in src/. QA found no Critical, High or Medium issues.
  • Low note: hives with only half boxes no longer show the frame-orientation marker (it was only ever drawn on a full box, and before the fix on the phantom one).
  • Doc: docs/features/hive-card-zero-full-brood-fix-plan.md.
