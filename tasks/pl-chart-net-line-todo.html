Profit & Loss chart – net profit line

Follows the income and expenses chart (tasks/pl-monthly-chart-todo.html, commit e09ba229). Feature doc: docs/features/profit-loss-tracker.md.

How it will work for the beekeeper

  • A blue line, Net profit (income minus expenses), runs across the bars with a dot on each month, or on each year in All Time. It is blue to match the Net Profit card.
  • When a month makes a loss, the line dips below a clear zero line, and the axis extends below €0 to show it.
  • This Year: the line stops at the current month. It does not run flat along €0 through months that have not happened yet.
  • Easier tapping: tapping anywhere in a month now shows all three figures together, "Income", "Expenses" and "Net profit", with no need to hit a thin bar. That helps with gloves.
  • The legend gains "Net profit". The screen reader summary and the hidden table gain a net column.

Review (12/11/2026)

Plan approved. Built as planned in one file, src/components/tools/ProfitLoss/MonthlyChart.tsx, plus the doc. No database changes.

  • Chart type: the chart is now a mixed Chart type="bar", with LineElement and PointElement registered. The net dataset is a line with order: 0, so it is drawn on top.
  • This Year: net is null for months still to come, so the line stops at today.
  • Tooltip: index mode with intersect: false. Points with no value are filtered out of the tooltip.
  • Order: the legend and tooltip are sorted in dataset order (Income, Expenses, Net profit). Without that, the line's drawing order would put it first.
  • Zero line: the zero gridline uses the ink colour at 2px. The other gridlines are unchanged.
  • Colours: net is blue-600 in light mode and blue-500 in dark mode. The dark expense red is now #c62828, because #b91c1c was under 3:1 contrast.
  • Screen readers: the summary now includes net, and the hidden table has a Net profit column ("Not yet" for months still to come).
