Profit & Loss – income by category

Follows the Sales Insights change (tasks/sales-insights-pl-todo.html, commit 8de45b84). Feature doc: docs/features/profit-loss-tracker.md.

Why

P&L shows only three totals and a flat list, so you cannot see what the income is made of. Sales Insights has an "Income by category" breakdown, but only people with the CRM see it. P&L is open to everyone in Tools.

What the code does today

  • ProfitLoss/index.tsx already loads every record with its category name, and filters by This Month, This Year or All Time (filteredRecords).
  • Sales Insights draws its "Income by category" bars inline (crm/insights/page.tsx). It groups income rows by category and sorts them largest first.

How it will work for the beekeeper

  • A panel Income by category sits between the totals and the list of records. It uses the same bars as Sales Insights: category name, amount, and a green bar sized against the largest.
  • It follows the time filter, so This Month, This Year and All Time each show their own breakdown. The heading says which period, for example "Income by category (this year)".
  • When the chosen period has no income, the panel is hidden, so the page does not grow for nothing.
  • There is no new query. It uses the records P&L already loads.
