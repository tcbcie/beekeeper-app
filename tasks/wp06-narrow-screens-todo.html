WP06 – Improve narrow-screen and enlarged-text layouts

Plan: docs/features/mobile-first-implementation-plan.html (WP06 and refinements). Findings: F07, R01, R04, H04, I07, V16. Layout only; no behaviour or data changes.

Changes

  1. Access screens wrap instead of clipping (R01).
    • Login, reset password and reactivate: the HiveCraic name block can wrap (flex-wrap, no leading-none).
    • On login, the Password label and "Forgot Password?" row can wrap onto two lines.
    • The main panel's padding is 20px on phones, 32px from sm up. It is 32px everywhere today, which leaves about 198px for content at double text size.
    • Overflow is not hidden any more than today, as it only clips the decorative background.
  2. Standalone links get 48px targets (R04): "Forgot Password?", "Request reactivation" (login) and "Back to Login" (reset page). Same look; taller tap area.
  3. Secondary forms stack on phones (F07): Purchase list Quantity/Unit and Supplier/Price, and Profit & Loss Date/Amount, become one column below 640px and stay two columns from sm up. (Priority already moved to its own row in WP04.)
  4. Hives top bar (H04), hives/page.tsx and FilterDisclosure.tsx:
    • The "+" button shows a word on phones too: "Add" next to the +, and "Add Hive" from sm up. Its spoken name stays "Add Hive".
    • When filters are active and the panel is closed, "Clear filters" shows on its own row on phones. Today it appears only after opening Filters. This is a shared component, so any other screen using the same phone layout gets it too.
  5. Photo picker reachable by keyboard (V16), InspectionForm.tsx: the file input becomes visually hidden (sr-only) instead of display: none, so Tab reaches it and the dashed box shows a focus ring.

Not changed until a phone shows a problem

The plan says fixed bars and the step bar change only where a problem is reproduced. These go on the phone checklist instead:

  • Inspection step bar and footer at 320px and with the largest text: does "Update Inspection" wrap, and do labels fit? (I07)
  • The space kept under the fixed New inspection bar on Hives, with large text.
  • The login page with browser zoom and the phone's own text size, not only the root-font stress test.
