Batch 19: Shared Foundations

Status: Done 22/10/2026. Tested by you; committed and pushed. Approved with the recommendations: requireUser() moves to batch 20, and the extra-small buttons go to 48px. This is Phase 2 fix batch 7.

Three agents checked the cross-cutting findings. All the user-visible bugs below are still in the code. The API sign-in clean-up (requireUser(), 21 route files) is a large refactor with no visible change, so I propose it as its own batch 20.

A. Linked records read the wrong way (5 visible bugs)

Supabase returns a to-one link (a hive's queen, a record's hive) as a single object, but these places read it as a list, so the value is always blank.

New tiny helper src/lib/embed.ts: firstOf(value) accepts an object or a list. The two local copies (queen compare, order detail) switch to it.
Apiary page (C7a-04): each hive's queen never showed. Fixed in useApiaryDetail.
Apiary page, Recent Activity (C7a-03): rows had no hive number.
Dashboard weather row (C3-04): your own bloom records never showed as confirmed. The link also gets its foreign key named.
Upcoming events (C9a-06): the apiary name never showed.
Queen page, sightings (C6-04): the hive number was always blank.

B. "Today" in UTC instead of Irish time

There are 130 client sites in 54 files. Most use new Date().toISOString().split('T')[0], which is the UTC date, so it's yesterday between midnight and 1am in summer time. One is wrong all summer.

Recipient queen birth date (C5b-05): when a batch has no emergence date, the date was a day early from late March to late October. Fix in useGraftDistributions.
getCurrentDate() and formatDateForInput() in date-utils.ts become local. One has no app callers, and the other's 10 callers all want local. Then every exact new Date().toISOString().split('T')[0] ("now" only) becomes getCurrentDate(). That covers about 80 default form dates and status dates: nucs, queen tracker, grafts, records, colonies, logbook, CRM and more.
Reports: the six report pages' own period maths (36 sites) use the existing getPresetRange().
Shifted dates fixed by hand: registration-code expiry options, best-before date, scale chart ranges, the "tomorrow" varroa task, team invite expiry.
CRM (C8b-07): both today() helpers become local. The order detail page's overdue badge could disagree with the list page.
Left alone on purpose: 9 sites that are deliberately UTC or convert stored values. Changing those would introduce bugs.

C. Touch targets: 48px

Tokens (C1-25): .fj-icon-btn (all 53 IconButton users), .fj-btn-sm and .min-touch-target go from 44px to 48px. The small button keeps its compact padding and font.
Confirm dialog (C1-24): its two buttons go from 40px to 48px. They were hand-sized, so the tokens didn't reach them.
Record cards: the Edit/Delete buttons on the Feeding, Harvest, Treatment and Varroa cards go from 40px to 48px.

D. User management expiry date (C9a-04)

Typing a date saved on every keystroke: typing the year "2026" wrote 0002, 0020, 0202 and 2026, each followed by a list refresh. Fix: keep a draft while typing, and save on blur or Enter.
