Security Batch 8: AI Tools Under Database Rules (AI-01)

Status: Done 17/10/2026; tested by you, committed and pushed. Finding: AI-01 (Medium), the last Medium from Phase 1.

What I found

  • Mel's 55 data tools (hives, inspections, varroa, queens, nucs, scales, traceability and so on) all use one secret-key database client (getSupabase() in src/lib/ai/tools/utils.ts). The database's access rules don't apply, so every tool's own user_id filter is the only protection.
  • Most tools filter correctly. But getColonyDetails and getColonyLineage look up parent and child colonies without a user filter, so another user's colony numbers can appear in the answer. That is exactly the kind of slip AI-01 is about.
  • None of the tools write anything. Only two things need the secret key: reading the caller's own BEEP/Wolf token (users can't read those columns), and logging unanswered questions for the admin "tool suggestions" list.
  • No code path runs AI-written SQL any more. The old execute_safe_query function can only be called with the secret key, and only the admin export uses it.

Plan (three files, no tool rewrites)

utils.ts: getSupabase() returns a user-scoped client built from the caller's own sign-in token with the public key, so the database rules apply to every tool query. The client is held for the length of one chat request (Node's request-local storage). If a tool runs without one, it fails rather than falling back to the secret key.
src/app/api/chat/route.ts: create that client from the request's token and run the chat request inside it (runWithUserSupabase). The tools' own code and the 55 tool signatures stay as they are, and their existing filters stay on top of the database rules.
scales.ts: only the two token look-ups (the caller's own BEEP/Wolf token) use a clearly named secret-key helper, getServiceSupabase(). The knowledge-base search, news search and unanswered-question log in rag.ts stay as they are: they only read shared content or write admin analytics.
Verify: type-check and lint, qa-engineer review, docs (AI tools doc and findings register).
You: build, then ask Mel a few questions (your hives, the last inspection of a hive, varroa counts, queens, a hive with a scale, a colony's lineage, a beekeeping knowledge question). Then commit and push.
