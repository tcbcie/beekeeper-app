Batch 37: Apiaries and Maps

Status: Implemented 24/10/2026, waiting for your test. This is Phase 2 fix batch 24. It covers the open Medium findings in chunk 7a: the apiaries pages, the location picker, the apiary layout map and the community map (C7a-06, 08 to 16, 18 to 21). Three agents checked each finding against the code, and I re-checked the key lines. No database change is needed.

A. Apiaries list: C7a-06, C7a-08, C7a-11, C7a-12, C7a-13

C7a-06, the "Shared" filter forgets itself: when the page loads, it doesn't know yet that you're in a team, so it switches a saved "Shared Apiaries" filter back to "All" and saves that. Now it only checks after loading has finished.
C7a-08, conservation area silently not created: if you enter only an Eircode, tick "Declare as NIHBS Conservation Area" and save without pressing lookup, the apiary gets its position from the Eircode. The conservation area code reads the empty form fields, so no area is created, or an existing one is deleted. Now it uses the same position that was saved.
  • Also, if the conservation area can't be saved after a new apiary has been, the form stayed open as "new", and saving again made a second apiary. Now the apiary is kept, the form closes, and a warning tells you to edit it to try again.
C7a-11, "last inspection" missing: the list fetches every inspection for every hive in one request to find each apiary's last inspection. Past 1,000 inspections the oldest are dropped, so an apiary inspected less often shows no date. With many hives, the request can also fail outright. It now reads in chunks and pages, as the hives list does.
C7a-12 / C7a-13, failures shown as "no apiaries", and double loading: if the list fails to load, you see the empty "no apiaries" screen. Now you get a warning, and the list you had stays. The page also loads the whole list twice on every visit, with nothing deciding which answer wins; it now loads once, and only the latest load applies.

B. Apiary detail: C7a-12, C7a-13

A network failure shows "Apiary not found". Now it says "Couldn't load this apiary" with a Try again button. "Not found" is kept for an apiary that really doesn't exist or isn't shared with you. Loads are numbered, so an older answer can't overwrite a newer one.

C. Location picker (apiaries, wild colonies): C7a-09, C7a-10

C7a-09, overlap zones never drawn: the purple zones where your flight radius overlaps other apiaries only appear after you change the radius or the map style. Tapping, dragging the pin and opening an existing apiary never draw them, because the tap handler holds old state. They're now drawn whenever the position changes.
C7a-10, zoom jumps on every tap: each tap flies the map back to zoom 14, so you can't zoom in to place the pin precisely. Now the map only moves when the pin is off-screen, and never zooms out. "Use my location" still flies there.

D. Apiary layout map: C7a-14, C7a-15, C7a-19, C7a-20

C7a-14, the map vanishes after a failed save: when a bench move, resize or delete fails, the map reloads and is swapped for "Loading apiary map…", which drops any drag or turn in progress and makes a phone page jump. Now a reload updates the map in place.
C7a-15, wrong "entrance is to its left / right": the direction to the apiary entrance was worked out from percentages of width and depth. Those are different distances unless the apiary is square, so on a 20 m × 10 m apiary a hive facing the entrance could be told it's to its left. It now uses the apiary's real proportions.
C7a-19 / C7a-20, small handles: the hive and bench turn handles and the bench grab tab go from 36px to 48px. The "3D view" and "Open 2D apiary map" links and the 3D view control go to 48px.

E. Community map: C7a-18, C7a-19, C7a-20, C7a-16

C7a-18, DCA buttons: "Drones seen" and "No drones" in the drone congregation area (DCA) popup call a global function through inline onclick. It works today, but it would stop the day the security policy is tightened, and any script on the page could call it. The buttons are now built properly, the batch 13 way, with no global. A failed save now shows a message instead of failing silently.
C7a-19 / C7a-20, small text and targets:
  • Popups and layer toggles: popup text goes from 10–12px to 14px, and the layer toggle labels from 12px to 14px.
  • DCA buttons: 14px text and 48px tall.
  • "Predict DCAs" and the two selects: 48px tall.
  • Map style, fullscreen and close buttons: 48px wide.
C7a-16, all markers rebuilt on every toggle: left as it is (your decision). It's real. Hiding one layer redraws everything. But the redraw is a few dozen markers; "all apiaries" is a single clustered layer. Splitting the 450-line drawing step into "draw" and "show/hide" is the biggest, riskiest change here, and it touches the style-reload fix from batch 30. I'd record it as accepted. Say if you'd rather I do it.

F. Map credits: C7a-21

The small map on the public jar and batch trace pages uses OpenStreetMap tiles with the credit turned off, which their terms don't allow. It now shows "© OpenStreetMap contributors". The location picker's bottom buttons partly covered the Mapbox credit; they move up a little. The community map's credit was already fine.
