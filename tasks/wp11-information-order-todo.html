It changes defaults only on evidence from beekeepers aged 50+. If no sessions are possible, it stays pending and today's order and defaults are kept. No participant results exist yet: the field-study pack is still "materials only".

What the code shows today

  • Dashboard on a phone, one column, in this order:
    1. Notices
    2. Greeting and summary
    3. Two quick actions
    4. Invitations, errors and wind warnings, each only when needed
    5. Seasonal card (with forecast tiles March to July)
    6. To do: first 5 jobs, then "Show all N jobs"
    7. My apiaries: all of them, those with jobs first
    8. "{Month} in Ireland": up to 5, a limit set in the database
    9. Upcoming Events: every task in the next 7 days, with no limit
    10. Recent visits: the latest 5, with View All Records
    11. Teams, folded closed
    12. Version

    Nothing else folds, and no open or closed state is remembered.

  • Hives on a phone: List is already the default (compact rows), and Cards is one tap away. The choice is remembered. Desktop always shows Cards. Nothing inside a card folds. Each card always shows:
    • the setup drawing, about 200px for 2 supers and 2 brood boxes
    • the model and photo row (03/11)
    • notes in full

    So it is about one hive per phone screen.

  • Already done, so not re-tested as new: To do stops at 5, Recent visits is 5 with View All Records, and List is the phone default.
  • Doc drift: dashboard-today-screen.md lists Recent visits after Teams; the code has it before. Notices, invitations, the error panel and the version line are missing from its table.

Decisions (05/11/2026): static mock-ups, ship nothing now, prepare for sessions

  1. D1 – How to build the B designs.
    • Recommended: static phone-size mock-ups (one HTML page with fictional data, kept in docs/reviews). There is no change to the app and no risk. They are good for finding work, appearance and preference, but cannot start a real inspection.
    • Alternative: an in-app preview, switched on only for the test account. It uses real screens and real tasks, but adds code to the live app that must be removed afterwards.
  2. D2 – Anything to ship now, without sessions?
    • Recommended: nothing. The plan says not to change defaults from screenshots.
    • Alternative: an optional "Show setup" fold on Cards that starts open, so nothing changes unless someone folds it, and remembers the choice. Low risk, but it is new UI without evidence.
  3. D3 – Can you run the sessions? They need the owner details the pack asks for (organiser, venue, consent, retention dates) and 6–8 beekeepers aged 50+. If not soon, WP11 stays pending and WP12 can go ahead without it.
