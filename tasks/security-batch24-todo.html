Batch 24: Public Embed, Mel's Tools and Group Reports

Status: Implemented 22/10/2026, waiting for your test. This is Phase 2 fix batch 11. The smaller admin and Tools items follow in batch 25.

A. GDD weather calls: the public tcbc.ie embed and Research (C7b-04)

Every visitor to the embed triggered up to 11 Open-Meteo archive calls, one after another. The current year was fetched 4 times and last year 3 times, from four parts of the page asking for the same data. Fix: one helper in src/lib/gdd.ts, fetchArchive(lat, lon, start, end). It shares a request that's already under way and remembers results while the page is open, so each distinct year is fetched once. The per-year loops run their years together. A request-id check stops a slower, older result from overwriting a newer one. Same change in PublicGDDTab and GDDDataTab; the dashboard's current-year GDD uses the helper too. Result: about 6 calls instead of 11, nearly all at once, and same results.

B. Mel's tools (C9b-13, C9b-14, C6-12)

11 tools ran one query per hive or nuc in turn: varroa counts, above threshold, needing treatment, treatment counts, last treatment, needing inspection, queen status, inspection counts, best performers, nucs needing inspection, colony overview. They now run those per-item queries together with Promise.all. They stay per-item on purpose, because one big query would hit Supabase's 1,000-row cap and silently drop the oldest hives. Errors are now checked rather than ignored.
Scale tools (compare readings, scale alerts): the vendor token is read once instead of once per hive, and the BEEP and Wolf calls run in groups of 5 with Promise.allSettled, so one slow or failing scale doesn't hold up or break the rest.
Lineage tool: 10 → 4 round trips, one query per generation, the same as the lineage tree in batch 23 (scoped to the user). Daughters, siblings and the batch load with the parents.

C. Group reports (C9b-11, C9b-12)

Rearing-group report: 6 → 3 round trips. It also had a list of every batch the group ever had sent in one request, which grows without limit (the same failure as the breeder-queen report). The distributions now filter through the batch join, so the list is gone.
NIHBS report: 5 → 3 round trips. The monthly-return lookup starts straight away, and the mating-apiary lookup joins the existing parallel group. The batch-id lists use fetchInChunks.
