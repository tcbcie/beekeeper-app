Hive Detail Page: Light-Mode Contrast Pass

Problem

The record lists and status badges on src/app/dashboard/hives/[id]/page.tsx were styled for dark mode only. In the default light theme they show pale text or light-on-murky badges, at about 1.5:1 to 2.5:1 contrast. That is well below WCAG AA (4.5:1 for text, 3:1 for icons), and hard to read for 50+ users outdoors.

Before and after (light mode)

ElementNowProposed
Feed type text Sugar Syrup (3:2) Sugar Syrup (3:2)
Honey weight 12 kg 12 kg
Queen Seen badge Queen Seen Queen Seen
Mite count (high) 14 mites 14 mites

Approach

This is a class-only change in one file. Every element gets a light-mode colour, and its current classes move behind dark:, so dark mode looks exactly as it does today. The pairs reuse patterns already in the codebase:

  • Badges: the same page's line 212 pattern: bg-X-100 text-X-800 border-X-300 dark:bg-X-900/50 dark:text-X-300 dark:border-X-800
  • Coloured text: line 453's pattern, using shade 700 or 800 in light mode and the current 400 in dark mode
  • Section icons: the Toast/ConfirmDialog pattern text-X-600 dark:text-X-400 (shade 700 for yellow, because yellow-600 is just under 3:1)

Review

  • 16 class-only line changes in src/app/dashboard/hives/[id]/page.tsx. Every item in the plan was done as specified.
  • A token-by-token scan found no dark-only colour left without a light pair. Each dark: class is the exact original class, so dark mode is unchanged.
  • All new classes are written out in full in the source, so Tailwind will generate them.
  • ESLint is clean and there are no type errors in src/. QA found no Critical, High or Medium issues.
  • Doc: docs/features/hive-detail-contrast-fix-plan.md.
