C. Service worker and sign-out (CLI-01, CLI-02)

public/service-worker.js: never cache /api/* responses. Those are signed-in, per-user data.
On every sign-out path, delete the service worker's runtime caches and the leftover hivecraic_impersonation admin tokens. I'll find all the paths first: the navbar, deactivation, account deletion and the impersonation banner. One shared helper keeps it simple.
Check how the worker update reaches installed copies of the app (cache name and activate step) without changing the version number. Version bumps stay manual.
