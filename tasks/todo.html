Mel voice input

Status: built, waiting for your tests and a real-phone check  ·  Date: 15 November 2026  ·  Feature doc: docs/features/mel-voice-input.md

Your request: Mel (the assistant) only takes typed questions; let beekeepers ask by voice as well.

How it was explored: two read-only agents covered Mel's chat code and the existing voice notes pipeline, alongside docs/features/voice-notes-field.md. The Technology Stack Review that was in this file is in git history (commit 3950ad7c and earlier).

1. What already exists

  • Mel's message box (src/components/chat/ChatInput.tsx, 73 lines) has a text box and a Send button. Mel opens as a bottom sheet on the phone and closes by unmounting, so a recording stops cleanly when Mel is closed.
  • Voice notes already record (src/hooks/useVoiceRecorder.ts) and transcribe (/api/voice-notes-transcribe) on the inspection and queen rearing forms. The route checks sign-in, subscription and rate limits, and biases towards beekeeping words.
  • The route always runs a second AI call that tidies text as an inspection note. That is wrong for a question and slower.

2. The design

User and moment: a beekeeper at the hive, gloved, with Mel open on their phone. One job: get the question into Mel's box without typing.

                                          stop: red, send disabled
  • Mic button beside Send, outlined and neutral, so the green Send stays the main action. While recording it turns solid red with a square icon, and its label reads "Stop recording". While transcribing it shows a spinner, and its label reads "Turning speech into text".
  • A status line above the row ("Listening… tap stop when you have finished") is read out by screen readers. Errors appear in the same place.
  • Words go into the box and are not sent automatically. The beekeeper checks for a misheard word, then taps Send. Text already typed is kept.
  • Both buttons are 48px. Send already was: .fj-icon-btn sets a 48×48px minimum that overrides its h-10, so it is left untouched. The pulse animation only runs when reduced motion is off.
  • The mic is hidden in browsers that cannot record.

Review against the design rules: I dropped my first idea, a purple mic as on the forms. Two filled buttons side by side compete, and Send is the primary action in this box. I also dropped auto-send, because a misheard "varroa" sent to Mel wastes a question.

3. Server change (small)

In src/app/api/voice-notes-transcribe/route.ts, read an optional form field cleanup. When it is "false", skip the tidy-up call and return the transcript as cleaned. The inspection and batch forms send nothing, so they behave as before.
