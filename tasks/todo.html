Filter the P&L records list by income or expenses

Status: built, waiting for your tests  ·  Date: 15 November 2026  ·  Feature doc: docs/features/profit-loss-tracker.md

Your request (with a screenshot of the records list): "I cannot filter for income and expenses on the list."

The invoice date default plan is in git history (3c49c99a).

1. What exists

The list shows every record for the chosen Period (This Month, Year or All Time). The only control is Period, at the top. Totals, chart, categories, list and CSV all use the same filteredRecords in ProfitLoss/index.tsx.

2. The design

  Expenses by category ...

  • A Show: All / Income / Expenses control directly above the records list, using the existing SegmentedControl, the same as Period. It defaults to All.
  • It filters the list and the CSV export, so an accountant can be sent just the expenses. Totals, chart and category panels stay for the whole period, because a profit figure needs both sides.
  • When nothing matches, the message says what to do, for example "No expenses in 2026. Tap Add Record to add one." The existing empty message ("No financial records yet") is left for when the period has no records at all.
  • It stays on screen rather than behind a filter button, as it is a single control people switch often while checking a list (the mobile-screen rule on filters).
