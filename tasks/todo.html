Technology Stack Review

Status: batches 1 and 2 built, waiting on your test run. Batches 3 and 4, error monitoring and push notifications not started  ·  Date: 13 November 2026

Your request: a full review of the frameworks, libraries and external services, and whether they are still the best fit for the application, the user experience and the functionality.

How it was done: three read-only agents swept the code, configuration and docs/features; I ran npm outdated and npm audit and checked the key claims myself. No tests or builds were run. The apiary map plan that lived in this file is in git history.

1. Verdict in short

The core stack is still the right fit and should stay. Next.js on Vercel, Supabase, Tailwind 4, the hand-built UI primitives, Dexie and the hand-written service worker suit a phone-first app for the apiary. Heavy libraries (charts, maps, 3D, Excel) are already loaded on demand. Nothing needs replacing wholesale.

What does need attention falls into four groups:

  1. Three free services are used outside their terms for a paid app: Open-Meteo, OpenStreetMap tiles and Nominatim.
  2. Two gaps that hurt field users: no error monitoring, and no real push notifications.
  3. The framework is one major version behind (Next.js 15 against 16), which also blocks one security fix.
  4. Housekeeping: one high-severity library update, four unused packages, one duplicate map library.

How the model change was checked

OpenAI’s documents do not say which settings gpt-6-luna accepts, so I sent five minimal live requests with the local key (a fraction of a cent):

  • It rejects the old max_tokens setting, so all four chat calls now use max_completion_tokens.
  • It accepts the temperature and JSON-only settings the app uses when reasoning is switched off, and returned valid JSON.
  • gpt-transcribe accepted the request shape the voice route sends (tested with a one-second tone, not speech).

Listed prices: gpt-6-luna $0.10 in / $0.50 out per million tokens against $0.15 / $0.60 for gpt-4o-mini; gpt-transcribe $0.0045 a minute against about $0.006. Both are cheaper.
