How it works

  • Press Select → each of your own hive cards shows a large checkbox; team/shared hives are not selectable.
  • A bottom bar shows the count with Move to apiary, Clone and Clear.
  • Move reassigns the apiary for all selected hives and clears their grid position (so the destination's unique row/position rule can't clash).
  • Clone creates a sister hive per selection: copies the box setup, hive type, apiary and order direction; new auto number …-copy(-2,-3…); no queen, no position, no history, dates = today.

Safety checks

  • Clone numbers are de-duplicated against all of the account's hive numbers (queried fresh, includes archived) — no collisions.
  • Verified DB nullability: only hive_number is NOT NULL; queen_installed_date etc. are nullable, so the queenless clone insert is valid.
  • Actions operate only on selected hives still loaded and owned by the user; a hive hidden by a later filter change is never silently written.
