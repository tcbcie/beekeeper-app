Plan — Swarm & Varroa Brood-Break Planner

Expand the existing TBR planner to support a second intervention (caging the queen), add an overall colony-population curve beside the forager curve, and surface the broodless window for oxalic-acid varroa treatment. Live calculator only — no database changes.

Core idea: both methods are a single zero-emergence window in the colony's emergence schedule, differing only in when it opens and what else it costs. This makes caging a small, additive generalisation of the existing TBR maths (TBR is the special case where the gap opens at day 0).

Review

All to-do items implemented. Summary of changes:

  • Model unification — both interventions now share one broodGap(c, method) helper (zero-emergence window). foragerForceAtOffset was generalised from the fixed 0/gapLen split to gapStart/gapEnd, so TBR output is byte-for-byte unchanged (gapStart = 0) and caging is purely additive.
  • New population curve — populationAtOffset integrates the same emergence over the full adult lifespan; simulateForagerCurve now emits { foragers, population } per day.
  • Varroa window — milestones gained broodlessStartDate/ broodlessEndDate (gapStart … gapEnd − cappedPhase) plus a caging releaseDate; surfaced as a purple oxalic-acid callout.
  • Method threading — method flows through coverage, recommendation, plan assembly and the (method-aware) food budget. Hook adds method state and resets the date override on switch.
  • UI — method toggle; two stacked charts (forager amber, population emerald, each % of own steady state); cage-duration preset (21 / 24 d); method-aware milestones, slider label, advanced fields, food card and explanation.
  • Food budget (minimal, as agreed) — caging drops the comb-draw line/cost and notes the nest is retained; full recompute deferred.
