Plan — Earlier break + hive-system & brood utilisation

Three planner refinements. Live calculator only — no database changes (frame_standards already exists with 9 systems).

1. Earlier break — the break-date slider is pinned at the feasible-earliest date; extend it ~30 days earlier so the user can model breaking sooner.
2. Hive system — replace the hard-coded Dadant 9,500 cells/frame with a picker over frame_standards; derive cells/frame from each system's real dimensions.
3. Brood utilisation — a % slider (wall-to-wall is never 100%) scaling usable cells per frame; drives the brood readout and the food budget's frame count.
