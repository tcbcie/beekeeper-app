Select hives on a phone

Status: built, waiting for your check on a phone  ·  Date: 16 November 2026  ·  Feature doc: docs/features/hive-bulk-actions.md (update)

Report from a user (WhatsApp, with screenshots): "just noticed when I went to move hives On iPhone, the hive select button only shows when phone is in landscape."

The hive card header plan that was in this file is in git history (5caa7f2a).

1. Root cause

In src/app/dashboard/hives/page.tsx:

  • Line 875: the toolbar Select button has hidden sm:flex, so it only appears at 640px and wider. An iPhone in landscape is wider than 640px, which is why it appears there.
  • Lines 864–870: commit b9391c7e (2 Nov, mobile native feel) moved the phone entry point inside the collapsed Filters panel as "Select several hives", on the basis that choosing several hives is occasional on a phone. Filters start closed on a phone, so the button is out of sight and nobody would think to look for it there.
  • Side bug: the toolbar button switches at 640px (sm), but the phone button uses useIsPhone(), which switches at 768px (md). Between 640 and 767px (a large phone in landscape, a small tablet), both buttons show.

2. The fix

I'll put a visible Select button on the hive count line on phones. That line already exists and has empty space on the right, so the list does not move down and the five-hives-on-first-view goal still holds. The toolbar row has no room for a fourth button at 390px wide: the apiary picker would shrink to nothing.

All the switching between the phone and wider layouts happens at one breakpoint, md (768px), the same as useIsPhone. It is done with CSS only, so the button doesn't flash on first load.

Desktop is unchanged.

4. Review

Built as planned. All the code changes are in src/app/dashboard/hives/page.tsx, about 10 lines in total.

  • Filters panel: the phone-only "Select several hives" button is gone from it.
  • Hive count line: this is now a row with the counts on the left (min-w-0, so a long line with "Need inspection" or "Treatments On" wraps instead of pushing the button off-screen) and a neutral "Select" button on the right (shrink-0 md:hidden). The button only shows while selection is off. Once selecting, the existing "Done selecting" button under the toolbar ends it.
  • Breakpoints: the toolbar "Select/Done" is now hidden md:flex and "Done selecting" is md:hidden. The phone layout, the bulk bar padding (pb-56 md:pb-24) and useIsPhone now all switch at 768px, so the 640–767px double button is gone.
  • CSS check: .fj-btn sets display: inline-flex inside :where(), which has zero specificity, so md:hidden on the Button wins.
  • Docs: docs/features/hive-bulk-actions.md now says where Select sits on a phone and why it moved.
