Team members editing hive setup & inspection super auto-sync

Decision confirmed: Full config edit + super sync. Loosen the hives UPDATE RLS so any team member with access to the shared apiary can edit a hive's setup; un-hide the Edit button for shared hives. DELETE stays owner-only.

Root cause (one rule, both symptoms)

Team members cannot UPDATE a hive they don't own.
  • RLS: hives_update_policy is USING (user_id = auth.uid()) — owner-only.
  • UI: HiveListCard.tsx:386 renders Edit/Delete only when hive.user_id === userId, so the Edit option is hidden for Hive 2 (owned by a different member).
  • Super not reflected: the auto-sync RPC adjust_hive_honey_supers is SECURITY INVOKER. When a team member saves the inspection, its UPDATE runs as them, is filtered to 0 rows by the owner-only policy, and changes nothing. A 0-row RLS-filtered update returns no error, so even the warning toast stayed silent.
