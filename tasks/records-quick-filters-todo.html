Records quick filters

Status: built, with the owner's answers: defaults on every opening, and no pre-fill from an automatically selected hive. Not yet tested in a browser or committed.

Proposal

Buttons always visible above the Filters panel, in the order asked for:

InspectionsFeedingVarroa checkVarroa treatmentHarvest
  • Defaults: My Records, Inspections, the first apiary, the first hive in that apiary. "First" means first in each drop-down, leaving out archived hives. For My Records, shared apiaries are skipped.
  • Drop-downs stay in the Filters panel for everything else, such as All Hives, All Types and Hive Archived. If one of those is chosen, no button is lit.
  • Changing apiary selects that apiary's first hive. Today it selects All Hives.
  • Clear filters returns to the defaults, and the Filters badge counts differences from them. Otherwise it would always read at least 3.
  • Links still win: dashboard links, hive page links and record links open what they point to, not the defaults.
  • Time period is unchanged.

Effects of defaulting to one hive

  • Search: today search only looks inside the current filters, so it would only look in one hive. While there is search text, the apiary and hive filters would be ignored, so a known record can still be found.
  • New records: forms pre-fill the hive from the filter. A hive selected automatically could mean a record saved against the wrong hive. See decision 2.
  • Empty lists: if the first hive has no inspections, the page opens with none shown. The message would name the hive and offer All Hives.

Decisions for the owner

1. When do the defaults apply? Recommended: every time Records is opened, as asked, unless a link says otherwise. The cost: the apiary and hive selection is shared with Hives, Tasks and Reports, so opening Records would also change what those pages show. The alternative is to apply them only when nothing has been chosen, and remember choices, but then the defaults would rarely be seen after first use.
2. Should New Record pre-fill the automatically selected hive? Recommended: no. Pre-fill it only when you picked the hive yourself, on the buttons, drop-downs or a link.
