Headline approach

Reuse the existing browser-print pattern (window.print() + @media print + qrcode.react) already used by src/app/dashboard/qr-tags/page.tsx. No new PDF library. A single LabelSheet component renders any list of labels at the chosen preset. Presets are data-driven so DYMO / Avery / die-cut Brother rolls can be added later without refactoring.

Deviations from the original plan

  • Item 3 (globals.css @page rules) was dropped. The existing /dashboard/qr-tags page already uses an isolated window.open() print window. printHtml.ts follows the same pattern, so @page sizing lives inside each print-job document instead of in global CSS. Cleaner; no risk of bleeding into other print flows.
  • Preset picker dropped from the modal. Each call site passes a fixed preset (brother_dk22251_queen or brother_dk22251_balkani). A picker would have been dead UI in v1.
  • Queens list reuses the existing Compare selection rather than adding a separate "select for print" checkbox column. The same row tick now drives both Compare and Print.
