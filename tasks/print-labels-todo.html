Printable Labels — Implementation Plan

Full design: docs/features/print-labels.md. This file is the actionable todo list; tick items off as we go.

Headline approach

Reuse the existing browser-print pattern (window.print() + @media print + qrcode.react) already used by src/app/dashboard/qr-tags/page.tsx. No new PDF library — users can save as PDF from the system print dialog if they want one. A single LabelSheet component renders any list of labels at a chosen page preset (Brother QL roll, DYMO, Avery sheet).

Todos

Foundation

  • 1. Confirm scope with user (the four questions above) before coding.
  • 2. Create src/components/labels/ with types.ts, presets.ts, Label.tsx, LabelSheet.tsx.
  • 3. Add @page rules per preset + a .print-labels root in src/app/globals.css (using the existing @media print block).
  • 4. New PrintLabelsModal wrapping LabelSheet with the preset picker and a Print button.

Wire-ups (per entity, in priority order)

  • 5. Hives — bulk button on dashboard/hives/page.tsx (scoped to current filter), single-hive button on dashboard/hives/[id]/page.tsx. Reuses the QR tag flow's QR rendering.
  • 6. Mating nucs — bulk + single from components/batches/ManageNucsTab.tsx; reuses existing NucQRCode data shape.
  • 7. Queens — bulk button on dashboard/queens/page.tsx, single button on dashboard/queens/[id]/page.tsx. Includes year-colour dot.
  • 8. Rearing batches — single label per batch, from dashboard/batches/page.tsx.
  • 9. Batch grafts (per cell) — bulk print of all cells in a batch, from BatchGraftsSection.
  • 10. Apiaries — single A4/A5 apiary sign from dashboard/apiaries/[id]/page.tsx (not a thermal label).

Polish & docs

  • 11. Cross-reference the existing QR-tag page so its bulk-print button can call the new LabelSheet too — eliminates the duplicated print code.
  • 12. Add a short note to each affected feature doc in docs/features/ linking to print-labels.md.
  • 13. Manual verification on Brother QL-820NWB (continuous and die-cut roll) and on an A4 sheet print.

Out of scope (v1)

  • Direct USB / Bluetooth printer comms — iOS doesn't support it.
  • Drag-and-drop label designer — keep to fixed presets.
  • Server-rendered PDF — browser's "Save as PDF" already covers this.
  • Print queue / history.

Risks & mitigations

RiskMitigation
Print dialog scaling differs per browser / OS.Use CSS @page with absolute mm units; recommend users disable "fit to page" in the dialog. Document this once in the print modal.
QR readability on small (29 mm) labels.Generate at a fixed pixel density (already done in qr-tags/page.tsx); cap content size; allow QR toggle off.
iOS printing inconsistencies via AirPrint.Stick to portrait single-label rolls for thermal; AirPrint handles sheets reliably.
Existing QR-tag page diverges from the new component.Item 11: refactor the existing bulk-print to use LabelSheet once it's stable.
