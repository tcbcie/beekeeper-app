Batch 21: Load Heavy Panels Only When Needed

Status: Done 22/10/2026. Tested by you; committed and pushed. Research keeps GDD as the default tab (your decision). This is Phase 2 fix batch 9; request waterfalls follow in batch 22.

Several pages download every panel they could show, including chart libraries, maps and QR codes, even though only one panel is visible at a time. On a phone over mobile data, that's the slow first load beekeepers feel. The fix is Next.js's standard dynamic() import, already used for the map picker and the dashboard weather row: a panel's code downloads the first time it's opened, with a short "Loading…" spinner. No behaviour changes.
